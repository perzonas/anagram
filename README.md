# Anagram

## Task

In the file (`src/main/resources/anagramlist.txt`) is a word list with one word per line.

The task consists in creating a program in Kotlin that finds all words in the list that have one or more anagrams (from the same file), and that lists these together with the original word. Note that not all words have anagrams. You should only find one-word anagrams.

An anagram is a word or phrase that is put together by shuffling the letters of another word or phrase (<http://en.wikipedia.org/wiki/Anagram>).

Each line in the result must contain the words that are anagrams of each other. For example like this:

```
akte teak kate
aldri arild
aller ralle
alt tal
andre rande denar ander
```
